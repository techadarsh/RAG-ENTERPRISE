##  Key Changes Explained

### 1. **Redis Added**
```bash
REDIS_HOST=redis
REDIS_PORT=6379
REDIS_DB=0
```
**Why:** Enables async document ingestion with job queue

### 2. **Simplified LLM Configuration**
```bash
# Old format (rigid)
LLM_HOST=ollama
LLM_PORT=11434
LLM_MODEL=mistral:7b-instruct-q4_K_M

# New format (flexible)
LLM_MODE=api
MISTRAL_API_URL=http://host.docker.internal:11434/api/generate
MISTRAL_MODEL=mistral
```
**Why:** Supports multiple LLM backends (Ollama, HuggingFace, Mistral API)

### 3. **Embeddings Integrated**
```bash
# Old (separate service)
EMBEDDINGS_HOST=embeddings
EMBEDDINGS_PORT=8000

# New (integrated)
EMBEDDING_MODEL=BAAI/bge-base-en
EMBEDDING_DIM=768
```
**Why:** Embeddings now part of backend service, simpler architecture

### 4. **PostgreSQL Removed**
```bash
# Old
PG_HOST=postgres
PG_PORT=5432
# ... etc

# New
# (removed completely)
```
**Why:** Not used in current RAG architecture, Milvus handles all storage

### 5. **Ingestion Upload Directory**
```bash
UPLOAD_DIR=/app/uploads
```
**Why:** Directory for async ingestion file uploads

## [x] Current Configuration Summary

### **Active Services**

1. **Backend (FastAPI)** - Main API service
   - Handles queries
   - Manages ingestion API
   - Integrates embeddings and LLM

2. **Milvus** - Vector database
   - Stores document embeddings
   - Semantic search

3. **Redis** - Message queue
   - Job queue for async ingestion
   - Status tracking

4. **Ingestion Worker** - Background processor
   - Processes uploaded documents
   - Generates embeddings
   - Inserts into Milvus

5. **Ollama** - Local LLM
   - Generates answers
   - Privacy-first

6. **Frontend (React)** - User interface

##  How to Use

### **1. For Development (Default)**
The current `.env` is configured for local development with Ollama:

```bash
# Already set in .env
LLM_MODE=api
MISTRAL_API_URL=http://host.docker.internal:11434/api/generate
MISTRAL_MODEL=mistral
```

### **2. For Mock Mode (Fast Testing)**
```bash
# Change in .env
LLM_MODE=mock
```

### **3. For Cloud LLM (HuggingFace)**
```bash
# Change in .env
LLM_MODE=api
MISTRAL_API_URL=https://api-inference.huggingface.co/models/mistralai/Mistral-7B-Instruct-v0.2
MISTRAL_API_KEY=hf_YOUR_TOKEN
MISTRAL_MODEL=mistralai/Mistral-7B-Instruct-v0.2
```
