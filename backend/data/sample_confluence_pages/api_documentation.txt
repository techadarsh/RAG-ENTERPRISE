GETTING STARTED

Base URL:
Production: https://api.company.com/v1
Staging: https://api-staging.company.com/v1
Development: http://localhost:8000/v1

Authentication:
All API requests require authentication using Bearer tokens.

Authorization Header:
Authorization: Bearer <your_api_token>

Rate Limits:
- Free tier: 100 requests/hour
- Pro tier: 1000 requests/hour
- Enterprise: Custom limits

AUTHENTICATION ENDPOINTS

POST /auth/login
Description: Authenticate user and receive access token

Request Body:
{
  "email": "user@example.com",
  "password": "secure_password"
}

Success Response (200 OK):
{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "refresh_token": "eyJhbGciOiJIUzI1NiIs...",
  "expires_in": 3600,
  "token_type": "Bearer"
}

Error Response (401 Unauthorized):
{
  "error": "invalid_credentials",
  "message": "Email or password is incorrect"
}

---

POST /auth/refresh
Description: Refresh access token using refresh token

Request Body:
{
  "refresh_token": "eyJhbGciOiJIUzI1NiIs..."
}

Success Response (200 OK):
{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "expires_in": 3600
}

---

POST /auth/logout
Description: Invalidate current access token

Headers:
Authorization: Bearer <access_token>

Success Response (200 OK):
{
  "message": "Successfully logged out"
}

PROJECT ENDPOINTS

GET /projects
Description: List all projects for authenticated user

Query Parameters:
- page: Page number (default: 1)
- limit: Results per page (default: 20, max: 100)
- status: Filter by status (active, archived, all)
- sort: Sort field (name, created_at, updated_at)
- order: Sort order (asc, desc)

Example Request:
GET /projects?page=1&limit=20&status=active&sort=created_at&order=desc

Success Response (200 OK):
{
  "data": [
    {
      "id": "proj_67890",
      "name": "RAG Chatbot",

ERROR CODES

Standard HTTP status codes are used:

2xx Success:
- 200 OK: Request successful
- 201 Created: Resource created
- 204 No Content: Request successful, no content returned

4xx Client Errors:
- 400 Bad Request: Invalid request parameters
- 401 Unauthorized: Authentication required or failed
- 403 Forbidden: Insufficient permissions
- 404 Not Found: Resource not found
- 422 Unprocessable Entity: Validation error
- 429 Too Many Requests: Rate limit exceeded

5xx Server Errors:
- 500 Internal Server Error: Server error
- 502 Bad Gateway: Upstream service error
- 503 Service Unavailable: Service temporarily down

Error Response Format:
{
  "error": "error_code",
  "message": "Human-readable error message",
  "details": {
    "field": "Additional context"
  }
}

RATE LIMITING

Rate limit headers are included in all responses:

X-RateLimit-Limit: 1000

{
  "error": "rate_limit_exceeded",
  "message": "Rate limit of 1000 requests/hour exceeded",
  "retry_after": 1800

WEBHOOKS

Configure webhooks to receive real-time notifications:

Supported Events:
- project.created
- project.updated
- project.deleted
- document.uploaded
- document.deleted
- user.joined
- user.left

Webhook Payload Example:
{
  "event": "document.uploaded",
  "timestamp": "2025-10-11T10:30:00Z",
  "data": {
    "document_id": "doc_22222",
    "project_id": "proj_67890",
    "uploaded_by": "user_12345"
  }
}

Webhook Security:
- Verify signature in X-Webhook-Signature header
- Use HMAC-SHA256 with your webhook secret

CODE EXAMPLES

Python:
```python
import requests

API_BASE = "https://api.company.com/v1"
TOKEN = "your_access_token"

headers = {
    "Authorization": f"Bearer {TOKEN}",
    "Content-Type": "application/json"
}

# Get user profile
response = requests.get(f"{API_BASE}/users/me", headers=headers)
user = response.json()
print(f"Logged in as: {user['email']}")
```

JavaScript:
```javascript
const API_BASE = "https://api.company.com/v1";
const TOKEN = "your_access_token";

async function getUserProfile() {
  const response = await fetch(`${API_BASE}/users/me`, {
    headers: {
      "Authorization": `Bearer ${TOKEN}`,
      "Content-Type": "application/json"
    }
  });
  const user = await response.json();
  console.log(`Logged in as: ${user.email}`);
}
```

cURL:
```bash
curl -X GET "https://api.company.com/v1/users/me" \
  -H "Authorization: Bearer your_access_token" \
  -H "Content-Type: application/json"
```
