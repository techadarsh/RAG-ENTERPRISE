# Logo Assets

Please download and place the following logos in this directory:

## Required Logos:

1. **Stats Perform Logo**
   - Filename: `statsperform-logo.png`
   - Source: https://www.statsperform.com/ (download from official website)
   - Recommended size: 200x60px or similar aspect ratio

2. **BITS Pilani Logo**
   - Filename: `bits-pilani-logo.png`
   - Source: https://www.bits-pilani.ac.in/ (download from official website)
   - Recommended size: 200x60px or similar aspect ratio

## How to Download:

### Stats Perform Logo:
1. Visit: https://www.statsperform.com/
2. Right-click on the logo → Save image as
3. Save as `statsperform-logo.png` in this directory

### BITS Pilani Logo:
1. Visit: https://www.bits-pilani.ac.in/
2. Right-click on the logo → Save image as
3. Save as `bits-pilani-logo.png` in this directory

## Alternative:
If you prefer using direct URLs, the code already supports loading from external sources.
