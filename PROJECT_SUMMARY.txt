🔧 TECHNOLOGY STACK
─────────────────────────────────────────────────────────────────────────────

Backend:
  • FastAPI          → Modern Python web framework
  • Python 3.10      → Core language
  • Uvicorn          → ASGI server

Vector Search:
  • Milvus 2.3.3     → Vector database
  • etcd             → Metadata store
  • MinIO            → Object storage

Embeddings:
  • BGE-Large-En     → BAAI/bge-large-en model
  • 1024 dimensions  → High-quality embeddings
  • Sentence Trans.  → Inference engine

LLM:
  • Mistral 7B       → Answer generation (API mode)
  • Mock Mode        → Demo/testing mode

Frontend:
  • React 18         → UI framework
  • Axios            → HTTP client
  • Nginx            → Static file server

Orchestration:
  • Docker           → Containerization
  • Docker Compose   → Multi-service management

 ARCHITECTURE FLOW
─────────────────────────────────────────────────────────────────────────────

User Query
    ↓
React Frontend (Port 3000)
    ↓ HTTP POST /ask
FastAPI Backend (Port 8000)
    ↓
RAG Pipeline
    ├─→ Embeddings Module (BGE-Large-En)
    │   └─→ Query Vector [1024-dim]
    ├─→ Milvus Vector DB (Port 19530)
    │   └─→ Top-3 Similar Documents
    ├─→ Context Builder
    │   └─→ Combined Text Context
    └─→ LLM Client (Mock/API)
        └─→ Generated Answer
    ↓
JSON Response
    ├─ answer
    ├─ sources[]
    └─ latency_ms
    ↓
Display in UI

🔐 CONFIGURATION
─────────────────────────────────────────────────────────────────────────────

File: backend/.env

MILVUS_PORT=19530                            # Milvus port
COLLECTION_NAME=enterprise_docs              # Vector collection
EMBEDDING_MODEL=BAAI/bge-large-en            # Embedding model
EMBEDDING_DIM=1024                           # Vector dimensions
LLM_MODE=mock                                # mock or api
MISTRAL_API_KEY=                             # (Optional) API key
MISTRAL_API_URL=https://api.mistral.ai/...  # API endpoint
DATA_DIR=/app/data                           # Document directory

🐛 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

Issue: "Connection refused"
Fix:   Wait 2-3 min for Milvus initialization

Issue: "Out of memory"
Fix:   Increase Docker memory to 8GB+ in settings

Issue: "Port already in use"
Fix:   Stop conflicting services or change ports

Issue: "Frontend can't reach backend"
Fix:   Check CORS settings, verify backend is running
